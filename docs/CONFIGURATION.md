## Format tokens

`chatFormat`, `nametagFormat`, `actionBarFormat`, `sidebarLines`, hologram text
and broadcast messages all expand the same tokens:

| Token | Value |
| --- | --- |
| `{name}` | The player's name |
| `{namecolor}` | Their chosen name colour |
| `{role}` | Highest staff role prefix |
| `{rolecolor}` | Highest staff role colour |
| `{rank}` | Progression rank prefix |
| `{rankcolor}` | Progression rank colour |
| `{rankname}` | Progression rank name |
| `{balance}` | Current balance, comma separated |
| `{symbol}` | Currency symbol |
| `{currency}` | Currency name |
| `{online}` | Players currently online |
| `{playtime}` | Total time played |
| `{kills}` | Player kills |
| `{deaths}` | Deaths |
| `{mined}` | Blocks mined |
| `{xp}` | Total XP |
| `{clan}` | Clan id, if any |
| `{server}` | Configured server name |
| `{health}` | Current health |
| `{maxhealth}` | Maximum health |

`{message}` is additionally available in `chatFormat`.

> `sidebarLines` may only use server-wide tokens such as `{server}` and
> `{online}`. Bedrock's scoreboard sidebar is a single world-global display,
> so per-player values belong in `actionBarFormat` instead.
